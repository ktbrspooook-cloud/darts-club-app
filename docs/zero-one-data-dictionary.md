# 01ゲーム データ辞書 v0.1

## 1. 目的

本書は、ダーツ部アプリにおける01ゲームの結果登録について、以下を定義する。

* 管理者が画面で入力する情報
* APIが受け取る情報
* DBへ保存する情報
* 保存済みデータからアプリ側で計算する情報

対象は最初の縦切り機能である、以下の流れとする。

```text
開催日作成
↓
01ゲーム結果入力
↓
DB保存
↓
開催日詳細表示
↓
全期間01ランキング表示
```

---

## 2. 対象範囲

v0.2では、以下のみを対象とする。

```text
ゲーム種別：01
ゲーム形式：301 / 501 / 701
参加者数：2〜4人
試合形式：個人戦
勝者：1人
```

以下は後続機能とする。

```text
Cricket
COUNT-UP
ダブルス
チーム戦
引き分け
推定RT
アワード
月間・直近3か月ランキング
```

---

## 3. 管理者が入力する情報

| 項目       | 形式              | 必須 | 説明                |
| -------- | --------------- | -: | ----------------- |
| 開催日      | event_id        | 必須 | 既に作成済みの開催日を選択する   |
| ゲーム形式    | 301 / 501 / 701 | 必須 | 01ゲームの形式          |
| 参加者      | user_id         | 必須 | 2〜4人を選択する         |
| 01平均スタッツ | 数値              | 必須 | 各参加者のゲーム結果として入力する |
| 勝者       | user_id         | 必須 | 参加者の中から1人を選択する    |

---

## 4. 入力値のバリデーション

| 項目       | ルール                       |
| -------- | ------------------------- |
| 開催日      | 登録済みのevent_idであること        |
| ゲーム形式    | 301 / 501 / 701のいずれかであること |
| 参加者数     | 2〜4人であること                 |
| 参加者      | 同じuser_idを重複して選択できない      |
| 01平均スタッツ | 数値であり、0より大きいこと            |
| 勝者       | 参加者の中から1人だけ選択されていること      |

---

## 5. APIで受け取るデータ

### エンドポイント

```text
POST /events/{eventId}/games/zero-one
```

### リクエスト例

```json
{
  "gameFormat": "701",
  "participants": [
    {
      "userId": "usr_komatsuzaki",
      "zeroOneAvg": 74.1
    },
    {
      "userId": "usr_mare",
      "zeroOneAvg": 68.9
    }
  ],
  "winnerUserId": "usr_komatsuzaki"
}
```

### API側で自動設定する値

```text
game_id
game_type
game_sequence
is_winner
created_by
created_at
updated_at
recorded_at
```

## 6. DBへ保存する事実データ

### Games

1ゲーム共通の情報を保存する。

| 項目            | 説明              |
| ------------- | --------------- |
| game_id       | ゲームを一意に識別するID   |
| event_id      | 紐づく開催日ID        |
| event_date    | 開催日             |
| game_sequence | その開催日の何ゲーム目か    |
| game_type     | ZERO_ONE        |
| game_format   | 301 / 501 / 701 |
| match_type    | FREE_FOR_ALL    |
| status        | CONFIRMED       |
| created_by    | 登録した管理者のuser_id |
| created_at    | 作成日時            |
| updated_at    | 更新日時            |

### GamePlayerResults

各ゲームにおける、参加者ごとの結果を保存する。

| 項目           | 説明                 |
| ------------ | ------------------ |
| game_id      | 紐づくゲームID           |
| user_id      | 参加者のユーザーID         |
| event_id     | 紐づく開催日ID           |
| event_date   | 開催日                |
| game_type    | ZERO_ONE           |
| game_format  | 301 / 501 / 701    |
| zero_one_avg | そのゲームの01平均スタッツ     |
| is_winner    | 勝者ならtrue、敗者ならfalse |
| recorded_by  | 記録した管理者のuser_id    |
| recorded_at  | 記録日時               |
| updated_at   | 更新日時               |

## 7. DBへ保存しない計算値

以下は入力・保存せず、GamePlayerResultsから都度算出する。

| 計算値         | 算出方法                  |
| ----------- | --------------------- |
| 当日平均01スタッツ  | その開催日における01平均スタッツの平均  |
| 最大瞬間風速      | 対象期間における01平均スタッツの最大値  |
| 全期間平均01スタッツ | 全期間の01平均スタッツの平均       |
| 勝数          | is_winner = true の件数  |
| 敗数          | is_winner = false の件数 |
| 勝率          | 勝数 ÷ ゲーム数 × 100       |
| ゲーム数        | GamePlayerResultsの件数  |
| ランキング順位     | 全期間平均01スタッツを比較して算出する  |

## 8. ランキングルール

### 対象条件

```text
全期間において、01を3ゲーム以上プレーしていること
```

### 並び順

```text
全期間平均01スタッツの高い順
```

### 同率順位

競技順位方式を使用する。

```text
1位
2位
2位
4位
```

### 参考記録

```text
01ゲーム数が2ゲーム以下の部員はランキング外とする。
ただし成績は非表示にせず、参考記録として表示する。
```

---

## 9. 設計上の原則

```text
入力するのは、ゲームごとの事実データだけ。
平均・ベスト・勝率・順位は、保存済みの結果から再計算する。
```

この方針により、誤入力を修正・削除した場合でも、成績・ランキングを正しく再集計できる。

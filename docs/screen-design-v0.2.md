# ダーツ部アプリ 画面設計 v0.2

## 1. 対象範囲

本書では、最初の縦切り機能として以下の画面を対象とする。

```text
開催日一覧
↓
開催日作成
↓
01ゲーム結果入力
↓
開催日詳細
↓
全期間01ランキング
```

対象ゲームは01のみとする。

```text
ゲーム形式：301 / 501 / 701
参加者数：2〜4人
勝者：1人
```

Cricket、COUNT-UP、個人成績、ホーム、推定RT、グラフ、部員招待は後続機能とする。

---

## 2. 共通UI方針

* 背景はダークネイビーを基本とする
* 文字色は白または淡いグレーを基本とする
* 選択状態やアクセントは紫〜青を使用する
* 登録・確定などの主操作は緑色を使用する
* PCでは左サイドバーを表示する
* 将来的にはスマホでも使えるようにするが、v0.2ではPC表示を優先する

---

## 3. 画面一覧

| 画面ID       | 画面名     | 主な利用者          | 目的                           |
| ---------- | ------- | -------------- | ---------------------------- |
| EVENT-01   | 開催日一覧   | admin          | 作成済み開催日を確認し、開催日詳細または開催日作成へ進む |
| EVENT-02   | 開催日作成   | admin          | 開催日情報と参加者を登録する               |
| GAME-01    | 01結果入力  | admin          | 01ゲームの結果を登録する                |
| EVENT-03   | 開催日詳細   | admin / member | 当日のゲーム履歴と日別成績を確認する           |
| RANKING-01 | 01ランキング | admin / member | 全期間の01平均スタッツランキングを確認する       |

---

## 4. EVENT-01：開催日一覧

### 目的

管理者が開催日を作成し、既存の開催日を選択して結果確認・結果入力へ進む。

### 表示項目

```text
開催日一覧
開催名
開催日
開始時刻
会場
参加予定人数
```

### 操作

```text
開催日を選択
→ EVENT-03：開催日詳細へ遷移

開催日を追加
→ EVENT-02：開催日作成へ遷移
```

### v0.2の表示イメージ

```text
開催日一覧

2026/06/20（土） 2026年6月ダーツ部
18:00〜21:00 / 社内ダーツスペース / 4名

2026/07/18（土） 2026年7月ダーツ部
18:00〜21:00 / 社内ダーツスペース / 0名

[ + 開催日を追加 ]
```

カレンダー表示は後続機能とする。

---

## 5. EVENT-02：開催日作成

### 目的

管理者が部活動の開催情報と参加者を登録する。

### 入力項目

| 項目   | 必須 | 入力形式         |
| ---- | -: | ------------ |
| 開催日  | 必須 | 日付           |
| 開始時刻 | 任意 | 時刻           |
| 終了時刻 | 任意 | 時刻           |
| 開催名  | 必須 | テキスト         |
| 会場   | 任意 | テキスト         |
| 参加者  | 任意 | 登録済み部員から複数選択 |

### 初期値

開催名は、開催日を選択した時点で以下を初期表示する。

```text
YYYY年M月ダーツ部
```

例：

```text
2026年6月ダーツ部
```

### 操作

```text
保存
→ 開催日を保存する
→ EVENT-03：開催日詳細へ遷移する

キャンセル
→ EVENT-01：開催日一覧へ戻る
```

---

## 6. GAME-01：01結果入力

### 目的

管理者が、選択した開催日における01ゲーム結果を登録する。

### 画面上部の表示

```text
開催名
開催日
現在登録されているゲーム数
```

例：

```text
2026年6月ダーツ部
2026/06/20（土）
本日3ゲーム目
```

### 入力項目

| 項目       | 必須 | 入力形式            |
| -------- | -: | --------------- |
| ゲーム形式    | 必須 | 301 / 501 / 701 |
| 参加者      | 必須 | 2〜4人を選択         |
| 01平均スタッツ | 必須 | 参加者ごとの数値入力      |
| 勝者       | 必須 | 参加者の中から1人選択     |

### 入力例

```text
ゲーム形式：701

参加者               01平均スタッツ        勝者
小松崎               74.1                  ○
mare                 68.9
佐藤                 71.5
```

### 主操作

```text
結果を登録
→ 結果を保存する
→ EVENT-03：開催日詳細へ戻る

登録して次のゲームへ
→ 結果を保存する
→ GAME-01を初期状態で再表示する
```

### 入力時に表示しないもの

以下は保存済みデータからアプリが計算するため、管理者は入力しない。

```text
最大瞬間風速
日別平均
全期間平均
勝率
ランキング順位
```

## 7. EVENT-03：開催日詳細

### 目的

選択した開催日に行われた01ゲーム結果を確認する。

### 表示項目

```text
開催名
開催日
開催時間
会場
参加者
ゲーム数
```

### 日別成績一覧

参加者ごとに、以下を表示する。

| 項目       | 説明             |
| -------- | -------------- |
| 名前       | 表示名            |
| ゲーム数     | 当日の01ゲーム参加数    |
| 当日平均スタッツ | 当日の01平均スタッツ平均  |
| 最大瞬間風速   | 当日の01平均スタッツ最大値 |
| 勝数       | 当日の勝数          |
| 敗数       | 当日の敗数          |

### ゲーム履歴一覧

各ゲームごとに、以下を表示する。

```text
01 / 701
ゲーム番号：3

小松崎：74.1　勝ち
mare：68.9　負け
佐藤：71.5　負け
```

### admin向け操作

```text
[ + 01結果を追加 ]
→ GAME-01：01結果入力へ遷移
```

v0.2では編集・削除機能は後回しとする。

## 8. RANKING-01：全期間01ランキング

### 目的

部員全体の01成績を、全期間平均スタッツで比較する。

### 表示項目

| 項目        | 説明        |
| --------- | --------- |
| 順位        | 競技順位方式    |
| 名前        | 表示名       |
| 平均01スタッツ  | 全期間平均     |
| ベスト01スタッツ | 全期間最高値    |
| 勝数        | 全期間勝数     |
| 敗数        | 全期間敗数     |
| 勝率        | 勝数 ÷ ゲーム数 |
| ゲーム数      | 全期間の01参加数 |

### ランキング対象

```text
全期間で01を3ゲーム以上プレーしている部員
```

### 参考記録

3ゲーム未満の部員は順位表に含めず、画面下部に表示する。

```text
参考記録

mare
平均01スタッツ：71.5
ゲーム数：2
ランキング対象まであと1ゲーム
```

### 同率順位

競技順位方式を使用する。

```text
1位
2位
2位
4位
```

## 9. 画面遷移

```text
EVENT-01：開催日一覧
├─ 開催日を追加
│  └─ EVENT-02：開催日作成
│     └─ 保存
│        └─ EVENT-03：開催日詳細
│
└─ 開催日を選択
   └─ EVENT-03：開催日詳細
      └─ 01結果を追加
         └─ GAME-01：01結果入力
            ├─ 結果を登録
            │  └─ EVENT-03：開催日詳細
            │
            └─ 登録して次のゲームへ
               └─ GAME-01：01結果入力

RANKING-01：全期間01ランキング
```

## 10. v0.2完了条件

以下がすべて動作した時点で、v0.2の最初の縦切りを完了とする。

```text
開催日を作成できる
↓
01ゲーム結果を登録できる
↓
登録内容がDBへ保存される
↓
開催日詳細でゲーム履歴を確認できる
↓
全期間01ランキングへ反映される
```
